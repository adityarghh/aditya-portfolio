# Aditya Raj — portfolio

A personal, responsive portfolio built with plain HTML, CSS, and JavaScript.

## Preview
Open `index.html` in Chrome. No build tools or dependencies required.

## Before publishing
- Replace `hello@example.com` with the email address you want public.
- Check each GitHub project link and point it to the correct repository.
- Confirm the project descriptions accurately reflect what you built.
- If you want to use a custom domain, deploy the folder to a static host such as GitHub Pages or Netlify.

## Design intent
This is deliberately more editorial and personal than a typical developer template: warm paper background, dark ink, acid yellow and orange accents, custom CSS project illustrations, direct copy, and restrained motion. No stock headshot, generic floating blobs, or scroll-triggered animation parade.
